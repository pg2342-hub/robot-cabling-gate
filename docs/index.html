Robot cabling go-live gate

Simulated data. A supervised pilot where a robot cables one rack per shift (54 copper management and 36 front-end fiber connections) for 15 shifts.

When can the robot work without a tech watching? Each shift is graded connection by connection: right port, latched, link up, label, clean fiber end face, fiber receive power, cycle time, nobody stepping in, and no live cable disturbed. The gate says GO only when 53 of 54 copper and 35 of 36 fiber connections are right the first time with no live cable (one already linked up, on this rack or a neighbor) disturbed. Misses the customer's network team fixed are reported but not counted against the robot. Ten GO shifts in a row, with no tech note that blocks unsupervised work, moves the robot to unsupervised shifts; a fiber-only miss lets copper go first. Built on golive-gate. Code on GitHub.

Stage timeline

A PARTIAL shift is a fiber-only miss, so the copper streak kept going: copper reaches 10 in a row first, which is why the plan can promote copper alone at the readout while fiber stays supervised. After shift 15 the GO streak reaches 10, so the robot works unsupervised from shift 16. Blocking notes from hand labels (no recorded Claude triage yet).
