Robot Cabling Go-Live Gate

A supervised pilot where a robot cables one rack per shift (54 copper management and 36 front-end fiber connections) for 15 shifts. When can the robot work without a tech watching? Simulated data.

Can the robot work unsupervised?

Yes, from shift 16. After shift 15 the GO streak reaches 10 with no blocking note. Copper reached 10 in a row first, after shift 14.

How a shift is graded

Each shift is graded connection by connection:

  • Right port
  • Latched
  • Link up
  • Label
  • Clean fiber end face
  • Fiber receive power
  • Cycle time
  • Nobody stepping in
  • No live cable disturbed

GO

53 of 54 copper and 35 of 36 fiber connections right the first time, with no live cable (one already linked up, on this rack or a neighbor) disturbed.

Copper first

A fiber-only miss is PARTIAL and lets copper go first. A PARTIAL shift is a fiber-only miss, so the copper streak kept going: copper reaches 10 in a row first, which is why the plan can promote copper alone at the readout while fiber stays supervised.

Unsupervised

Ten GO shifts in a row, with no tech note that blocks unsupervised work, moves the robot to unsupervised shifts.

Misses the customer's network team fixed are reported but not counted against the robot. Built on golive-gate.

Weekly update to the customer

Claude writes each week's update from that week's fact sheet; a rule check holds any number not in the sheet, and a Claude judge holds any unsupported claim. Gate: GO (details).

Robot cabling pilot, week 1 (shifts 1-5): supervised next week

Week 1 covered shifts 1-5. The robot cabled 5 racks and 450 connections. First-pass results were 259 of 270 on copper and 173 of 180 on fiber, for 96.0% overall. There were 17 interventions, or 3.8 per 100 connections, and 1 miss was customer-caused. We recorded 1 live disturbance and 3 safety stops. Against the gate, the week had 0 go shifts, 1 partial and 4 no-go, and 3 shifts carried a blocking note. The go streak stands at 0, and 10 consecutive go shifts are needed before unsupervised work. The robot will work supervised next week because the gate has not been met.

Gate: sent (all checks passed)

Robot cabling pilot, week 2 (shifts 6-10): supervised next week

This week the robot cabled 5 racks, 450 connections. First-pass success was 268 of 270 on copper and 179 of 180 on fiber, 99.3 percent overall. There were 2 interventions, 0.4 per 100 connections, and 1 miss was customer-caused. There were 0 live disturbances and 0 safety stops. All 5 shifts passed the gate as go, with 0 partial, 0 no-go, and 0 shifts carrying a blocking note. The go streak stands at 5 against the 10 required to move to unsupervised work. Because the streak has not reached 10, the robot stays supervised next week.

Week 3 cabling pilot update: robot moves to unsupervised work next week

Tech note triage

30 constructed tech notes, 3 runs each. Claude tags each note (failure mode, owner, safety, blocks unsupervised work, needs review) and writes a one-line summary; rules grade the tags and a Claude judge grades the summary. Gate: GO (every note and verdict).

Data

Simulated. Port names, labels, light levels, cycle-time ceilings and every miss are made up; the 30 tech notes are constructed. Claude runs are replayed from recordings/, so no API key is needed.
